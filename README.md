# ResepKu

Implementasi Modul Praktikum 7 Aplikasi Mobile: asset logo, font Poppins,
foto resep dari jaringan dengan loading dan placeholder saat gagal, serta
tampilan daftar dan grid. Filter cuisine berlaku pada kedua tampilan dan
favorit tetap dikelola oleh Provider.

## Menjalankan aplikasi

Jalankan `flutter pub get`, lalu `flutter run` dari folder proyek ini.
Foto resep memerlukan koneksi internet pada Android; logo dan placeholder
tersedia sebagai asset lokal.

## Fitur praktikum

- Home dengan logo, filter cuisine, dan pergantian List/Grid.
- Detail resep dengan foto, jumlah porsi, kalori, dan bahan.
- Favorit dengan thumbnail, pemisah antarbaris, hapus dengan swipe, dan
  konfirmasi hapus semua.
- Mode gelap dan footer identitas dari Modul 6 tetap dipertahankan.
